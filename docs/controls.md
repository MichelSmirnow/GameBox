# Управление GameBox

Одна страница — вся приставка. Всё то же самое есть внутри устройства:
**Меню → Настройки → Управление в играх** (справка по каждой игре) и
**Настройки → Кнопки / Джойстик** (общая справка по консоли).

## Кнопки консоли

| Кнопка | Пин | В меню | Внутри игры |
| --- | --- | --- | --- |
| **ВЫБОР** | GPIO4 | войти в пункт / подтвердить | главное действие: забросить, подсечь, выстрелить, крутить, поставить клетку |
| **НАЗАД** | GPIO5 | шаг назад, к выходу | шаг назад по странице, из поп-апа — закрыть |
| **СБРОС** | GPIO6 | — | **табло рыбалки с любой страницы**; в остальных играх — новая партия/поле |
| **МЕНЮ** | GPIO7 | — | выход из игры в меню приставки |
| **Стик (нажатие)** | GPIO3 | — | категории зелий и зон, список предметов в Buckshot, автокрутка в RNG, старт/стоп в «Жизни» |
| **Джойстик влево/вправо** | GPIO0/1 | листать пункты | горизонтальные страницы (табы) |
| **Джойстик вверх/вниз** | GPIO0/1 | листать пункты | вертикальные страницы и выбор внутри страницы |

Долгое нажатие **ВЫБОР** (600 мс) — там, где нужно (например, зум в «Жизни»).
Долгое нажатие **МЕНЮ** — всегда выход в меню приставки.

### Как работает джойстик

* Считывается АЦП, центр запоминается при включении (и по «Калибровке»).
* Переключение срабатывает только при отклонении сильнее порога `1100 мВ`.
* После переключения нужно **вернуть стик в центр** (в пределах 350 мВ) или
  отклонить его **в противоположную сторону** — иначе повторного шага не будет.
* Одно отклонение = один шаг, поэтому списки не «убегают».
* Если страницы листаются не в ту сторону — `JOY_INVERT_X/Y` в `config.h`.

## Приставка

* **Загрузка** — логотип и вращающийся полукруг, затем меню.
* **Меню**: Игры · Настройки · Перезагрузка (ВЫБОР — войти, ВНИЗ/ВВЕРХ — выбрать).
* **Карусель игр**: одна игра на экран, обложка автора 128×46, название,
  номер и мигающие треугольники по краям, ВЛЕВО/ВПРАВО — листать, ВЫБОР — играть.
* **Настройки**: Кнопки · Джойстик · Управление в играх · Калибровка ·
  О приставке · Сброс данных.

## Игры

### Симулятор рыбалки (6 страниц)
| Страница | Что делать |
| --- | --- |
| Удочка | ВЫБОР — забросить; когда поплавок дёрнется — ВЫБОР снова (подсечь). ВНИЗ — прокачка удочки |
| Лодки | ВВЕРХ/ВНИЗ — лодка, ВЫБОР — купить / сделать активной. Лодки ловят сами. Последняя страница — **своя прокачка удачи лодок** (отдельно от удочки) |
| Холодильник | ВВЕРХ/ВНИЗ — вид рыбы, ВЫБОР — продать вид, СТИК — продать всю рыбу |
| Зелья | ВВЕРХ/ВНИЗ — зелье, ВЫБОР — сварить и применить, СТИК — категория зелий |
| Зоны | ВВЕРХ/ВНИЗ — зона, ВЫБОР — купить пропуск / перейти, СТИК — категория |
| Престиж | ВЫБОР — новый путь (нужна последняя зона и деньги), звание 1–5 |
| **СБРОС на любой странице** | табло: баланс, улов, активные эффекты |

### SPTS (5 страниц)
| Страница | Что делать |
| --- | --- |
| Тренировка | ВВЕРХ/ВНИЗ — навык (качается сам, пока страница открыта), ВЫБОР — рывок |
| Зоны | СТИК — категория навыка (как зелья в рыбалке), ВВЕРХ/ВНИЗ — зона внутри категории, ВЫБОР — тренироваться здесь |
| Арена | ВВЕРХ/ВНИЗ — бот, ВЫБОР — автобой на очки |
| Магазин | ВВЕРХ/ВНИЗ — навык, ВЫБОР — купить множитель (до x5) |
| Итоги | сводка навыков и боёв |

Зоны SPTS: 106 зон из пяти списков автора — сила удара (20), прочность (28),
психика (17), скорость (21), прыжок (20). Каждая зона качает **только свой
навык**, следующая зона того же навыка даёт **вдвое больше** (множитель `2^n`),
а открывается **уровнем этого навыка** (`2 + 4n + n²`).

### Buckshot Roulette
| Экран | Что делать |
| --- | --- |
| Интро → отказ от ответственности | ВЫБОР — принять |
| Раунд | ВЫБОР — дальше |
| Ход | ВЛЕВО/ВПРАВО — цель (в дилера / в себя), ВЫБОР — открыть список предметов, СТИК — выстрелить |
| Конец | ВЫБОР — новая партия |

Предметы: сигарета (+1 жизнь), лупа (посмотреть патрон), пиво (выбросить патрон),
пила (следующий выстрел x2), наручники (дилер пропускает ход), инвертор
(перевернуть патрон), аптечка (лечение с риском), телефон (подсказка о патроне).
Предметов в раунде: по 2 за раунд каждой стороне (до 8). Три раунда, жизней
2 / 4 / 6, патронов — по формуле автора `2..(10-(4-раунд))`, холостых примерно
треть. Все кадры (заставка, ванная, стол с дробовиком, выстрелы, экраны патронов,
жизней и раундов) — графика автора из его BuckshotRoulette.ino.

### RNG: крутки (5 страниц)
| Страница | Что делать |
| --- | --- |
| Крутка | ВЫБОР — крутить; СТИК здесь — включить/выключить автокрутку |
| Коллекция | ВВЕРХ/ВНИЗ — страницы списка аур |
| Зелья | ВВЕРХ/ВНИЗ — зелье, ВЫБОР — купить и выпить. Зелья Sol's RNG: Lucky, Speed, Mixed, Gladiator, Forbidden I/II, Strange I (случайный эффект из The List I), Heavenly I |
| Улучшения | ВВЕРХ/ВНИЗ — пункт: автокрутка, удача, скорость; ВЫБОР — купить за пыль |
| Итоги | всего круток, пыль, лучшая аура, сколько открыто |

Ауры: 48 штук, названия и шансы — с вики Sol's RNG (от `Common` 1/2 до
`Virtual` 1/2 500 000).

### Игра «Жизнь»
| Режим | Что делать |
| --- | --- |
| Редактор | джойстик — курсор, ВЫБОР — поставить/убрать клетку, СТИК — запустить, СБРОС — очистить |
| Симуляция | ВЫБОР — пауза/продолжить, ВВЕРХ/ВНИЗ — скорость, ВЛЕВО/ВПРАВО — шаг на паузе, СТИК — назад в редактор, СБРОС — очистить |
| Зум | удержать ВЫБОР (600 мс) |

Справа — панель: поколение, время, шаг (мс), население, статус (правка/идёт/пауза).

## Сохранения

Прогресс пишется в NVS автоматически: деньги и рыба, навыки SPTS и очки,
рекорды Buckshot, ауры RNG, настройки. «Настройки → Сброс данных» удаляет всё,
«СБРОС» внутри игры сбрасывает только текущую сцену.
