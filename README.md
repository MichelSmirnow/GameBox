# GameBox — приставка на ESP32-C3 Super Mini

Пять игр на карманной консоли: OLED 128×64, аналоговый джойстик, четыре кнопки,
полная русская локализация, сохранения в NVS. Код готов к прошивке из Arduino IDE,
внешние библиотеки не нужны.

| | |
| --- | --- |
| Плата | ESP32-C3 Super Mini (Arduino IDE, «ESP32C3 Dev Module») |
| Экран | SSD1306 128×64, I2C, 0x3C (SDA — GPIO8, SCL — GPIO9) |
| Ввод | джойстик KY-023 (X — GPIO0, Y — GPIO1, кнопка — GPIO3), кнопки ВЫБОР/НАЗАД/СБРОС/МЕНЮ — GPIO4/5/6/7 |
| Звук | пьезо на GPIO10 (необязательно) |
| Хранилище | NVS через `Preferences` |

## Быстрый старт

1. `docs/README.md` — как прошить (шаги, настройки платы, типичные проблемы).
2. `docs/wiring.png` — схема подключения, `docs/wiring.md` — таблица пинов.
3. `docs/controls.md` — управление: консоль и каждая игра.
4. `preview/all_screens.png` — все 78 экранов приставки, `preview/screen_*.png` — по одному,
   `preview/contact_sheet.png` — вся 1-битная графика по отдельности.
5. Прошивать: открыть `GameBox/GameBox.ino` в Arduino IDE и нажать «Загрузить».

## Графика автора

Исходники GameBox от Michail Smirnow (архив Google Drive) использованы напрямую:
его image2cpp-кадры Buckshot 128×64, его PNG рыб и интерфейса рыбалки, его
обложки меню. Всё это лежит в `src/gfx/gfx_their.cpp`, собирается скриптом
`tools/gen_their_art.py` (PNG нигде не хранятся — только 1-битные массивы).
Мои собственные картинки — только дополнение (`src/gfx/gfx_data.cpp`).

## Что внутри

```
GameBox.ino            setup() / loop()
src/core/              дисплей, графика, шрифты, ввод, меню, настройки, справка
src/games/             рыбалка, SPTS, Buckshot Roulette, RNG, игра «Жизнь»
src/gfx/               1-битная графика: моя (gfx_data) + автора (gfx_their)
tools/                 генераторы шрифтов, графики, схемы и симулятор для ПК
```

Игры в двух словах:

* **Симулятор рыбалки** — 38 рыб автора (его спрайты) + 6 новых, лодки-автолов
  с отдельной удачей, холодильник, 22 зелья, 6 зон с пропусками, престиж 1–5.
  Удочка в той же зоне всегда ловит лучше лодок.
* **SPTS** — 106 зон автора: каждая качает один навык, множитель `2^n`,
  открытие по уровню навыка; арена и магазин множителей.
* **Buckshot Roulette** — его кадры и его правила: три раунда, жизни 2/4/6,
  предметы по 2 за раунд, дилер с предметами и памятью о патронах.
* **RNG** — крутки, 48 аур и 8 зелий с вики Sol's RNG, автокрутка, улучшения, итоги.
* **Игра «Жизнь»** — редактор поля, зум, скорость, пауза, панель с показателями.

## Проверка без платы

В `tools/` лежит симулятор: он собирает весь код на ПК, прогоняет сценарий
и выгружает кадры 128×64 в PNG.

```bash
cd GameBox
python3 tools/gen_screens.py      # сборка + все экраны в preview/
python3 tools/gen_assets.py       # перерисовать графику
python3 tools/gen_diagram.py      # перерисовать схему
```

Симулятор заодно проверяет вёрстку: после каждого кадра он сравнивает рамки всех
надписей и печатает список наложений (`! имя_экрана «текст» (x,y) x «текст»`).
Сейчас их ноль — при правках удобно ориентироваться на этот отчёт.
